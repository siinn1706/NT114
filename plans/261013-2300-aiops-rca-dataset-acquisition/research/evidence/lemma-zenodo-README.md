# LEMMA-RCA: A Large Multi-modal Multi-domain Dataset for Root Cause Analysis

This Zenodo record provides archival metadata and access instructions for LEMMA-RCA, a large multi-modal, multi-domain dataset for root cause analysis (RCA).

Due to the large size of the dataset, the data files are hosted through the project website:

https://www.lemmarca.info

The website provides download instructions, documentation, dataset structure, and benchmark resources.

## Dataset version

Version: v1.0.0

## Contents of this Zenodo package

This package contains the minimal archival documentation for the dataset:

- `README.md`: overview and citation information.
- `dataset_card.md`: dataset description, intended use, access, ethics, and limitations.
- `metadata.json`: machine-readable metadata.
- `access_instructions.md`: how to obtain the dataset and code.
- `LICENSE_NOTICE.md`: license and access notice.

The full data are not included in this Zenodo upload because of their large size. The canonical access point is the project website.
