# Access Instructions

The full LEMMA-RCA dataset is hosted outside this Zenodo record because of its large size.

Please use the project website as the canonical access point:

https://www.lemmarca.info

The website should provide:

1. dataset download or request instructions;
2. data structure and schema documentation;
3. preprocessing instructions;
4. benchmark code or links to code;
5. license and access terms for each sub-dataset;
6. update and maintenance information.

For reproducibility, users should record the dataset version used in their experiments.

Current version: v1.0.0

Dataset DOI: `https://doi.org/10.5281/zenodo.20516735`
