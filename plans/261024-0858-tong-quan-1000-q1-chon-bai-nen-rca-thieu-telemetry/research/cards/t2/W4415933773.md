## Question
Let an LLM do fine-grained RCA (root cause entity + fault type + remediation) over logs/metrics/traces despite context-window limits and dynamic dependency graphs (Abstract; §I).

## Method
Three small learned tools plus one LLM: T1 dual-branch diffusion aligns logs (Drain+TF-IDF condition) and trace KPIs into time series (§III.A, Eq. 1-8); T2 FFT high-pass + frequency-domain attention causal graph + GAT, BCE loss outputs per-entity root-cause probability (§III.B, Eq. 9-20); T3 Transformer+GAT fault-type classifier with weighted BCE (§III.C). GPT-4 expert agent receives tool outputs via template (§III.D, Fig. 3).

## Data and systems
Dataset A: AIOps Challenge, HipsterShop (Online Boutique), 10 services x 4 pods, 6 nodes, 15 fault types, split by Pod/Service/Node (A_p, A_s, A_n). Dataset B: SocialNetwork, 21 services, 3 fault types, Zenodo (§IV.B.1). Training also uses an extra normal-run dataset for T1 pre-training (§IV.B.4).

## Modalities
Logs, metrics, traces, aligned into entity time series.

## LLM
GPT-4 as RCA expert (report generation); localization and classification are done by the non-LLM tools (§III.D).

## Baselines
HolisticRCA, Eadro, DejaVu, TimesNet, SegRNN, Transformer, PatchTST, AutoFormer, LightGBM (classification) (§IV.B.2, Table II).

## Metrics
Acc@k (k=1,3,5) with formula Eq. 26 over fault set S; micro/macro P/R/F1 for fault type (§IV.B.3).

## Main results
- Table II: TAMO Acc@1/3/5 = 71.87/82.14/88.83 (A_s), 64.28/80.36/87.50 (A_p), 84.37/91.96/97.77 (A_n), 72.22/80.55/86.11 (B). HolisticRCA is within ~1-6 points on A_s/A_p; DejaVu beats TAMO on A_n (81.25 Acc@1 but few samples).
- Fault classification MiF1 0.68/0.70/0.88/0.65 (Table II); on B TAMO MiF1 0.6538 is not best of all metrics (LightGBM MiPr 0.78).
- Ablation (Table III, one dataset): w/o T1 Acc@1 43.75, w/o FFT 53.13, full 72.22.
- Training 5.7 s/epoch on A, inference 0.17 s/sample on RTX 3090 (§IV.F, Fig. 5); total tools 10.96M params (Table IV).
- Single fixed seed, no CIs (§IV.B.4).
