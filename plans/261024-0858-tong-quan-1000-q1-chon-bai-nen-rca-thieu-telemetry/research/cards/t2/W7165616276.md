## Question
Can LLM RCL avoid context explosion and serial shallow reasoning by one agent per span, recursing on the trace graph in parallel (Sec. I, IV)?

## Method (Sec. IV)
- Data tools: Trace Tool (child spans), Metric Tool (n-sigma, n=3, window +/-delta=60 s), Log Tool (heuristic relevance filter).
- Dedicated Agent per span: self-state verification (Fig. 5 prompt) then evidence consolidation of child evidence (Fig. 6 prompt); Agents Pool K=100.
- Diagnosis Synthesizer merges Root-Level Diagnosis Report and Global Evidence Graph into a ranked list.

## Data and systems
AIOps2022 (7 services, 44 pods, 6 nodes), Augmented-TrainTicket (Nezha, 41 services), RCAEval RE2-OB (Sec. V-A.1). Failure = request latency > 100x average (Sec. II-A).

## Modalities
Traces (backbone) + metrics + logs as tool evidence. AIOps2022 logs lack SpanID (appendix C), so effectively no per-span logs there.

## LLM
Claude-3.5-Sonnet (default) and Qwen-3.6-Plus, both closed APIs, as every agent plus synthesizer. Table III: Llama-3.1-70B, DeepSeek-R1-Qwen-32B, GPT-4 and Qwen-2.5 variants are far worse (MRR 4-67 vs Claude 55-89 per subset).

## Baselines
Non-LLM: CRISP, TraceContrast, TraceRank/TraceRCA, MicroRank, RUN, Microscope, CausalRCA, Eadro, Nezha, BARO. LLM: CoT, RCAgent, mABC, GALA (Sec. V-A.2).

## Metrics
Recall@k, MRR = mean(1/rank) over |A| (Eq. 11). Paired Wilcoxon test p<0.05 vs mABC/GALA (MRR p=0.012); seeds for sensitivity (Sec. V-B, V-F).

## Main results (Table I, MRR)
RCLAgent(Qwen-3.6-Plus) 73.24 AIOps2022 / 86.47 TrainTicket / 71.03 RCAEval; Claude: 69.73 / 74.08 / 62.97. Best baselines: mABC 58.05, Nezha 90.37 (TT only; ~0 on RCAEval), GALA 58.93. Latency 41-60 s per query vs 85-195 s for LLM baselines; BARO 0.1-0.7 s (Table II). Ablation (Fig. 7): both RLDR and GEG help.

## Artifact availability
github.com/LLM4AIOps/RCLAgent-V2 (footnote 1); license/instructions not in text. Prompts in Fig. 5-6; decoding settings and synthesizer prompt not given. Server 24 CPU / 400 GB RAM; no GPU needed except via API.

## Limitations / failure modes (Sec. VI)
Needs trace coverage; without traces degenerates to ReAct (cost up, accuracy down); blind-spot/unsampled spans misattribute to neighbours; hallucination, LLM cost; baselines partly re-implemented.

## Missing telemetry
Discussed qualitatively (absent traces, missing spans) but not tested; no controlled drop experiment. Natural gap: no logs on AIOps2022.
