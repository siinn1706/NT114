# W7203837764 - CHASE: A Causal Hypergraph based Framework for Root Cause Analysis in Multimodal Microservice Systems

- Version read: submittedVersion (arXiv 2406.19711v2 preprint, 11 pp); text sha256 9de4767e7aa0cf5e217f76adc1033f5d0c144f2acd4431328e225255b8ce55e9
- Reader: r1. F_total 21, t2_gate 1.

## Question
Localize the root-cause instance of a trace-level anomaly using traces, logs and metrics together in an end-to-end trainable model (Abstract, §I).

## Method
Invocation graph with instance, log and metric nodes (§III-A); heterogeneous attention gives per-instance anomaly embeddings (§III-B); a hypergraph built from ancestor/descendant sets propagates causality, and a detection head scores each instance (§III-C, Algorithm 1, Eq.14-15).

## Data and systems
GAIA/MicroSS (10 instances, 1,099 static traces, 160 for training) and AIOps 2020 (68 injected failures, dynamic topology) (§IV-A1).

## Modalities
Traces (topology), logs (FastText of templates), metrics (time-series transformer) (§III-A).

## LLM
None; the conclusion proposes an LLM encoder as future work (§V).

## Baselines
PC, GES, CloudRanger, MicroRCA, TrinityRCL, CausalRCA, DiagFusion (§IV-A2); several are n/a on AIOps 2020 (Table II note).

## Metrics
A@1, A@3, Avg@5 over |D| anomaly traces (Eq.16-17); on AIOps 2020 only Percentage@n of anomalous traces detected (Eq.18), which is not an RCA metric (§IV-A3).

## Main results
- GAIA A@1 0.6135 vs TrinityRCL 0.4503, DiagFusion 0.4121; A@3 0.8823; Avg@5 0.8276 (Table II).
- AIOps 2020 Percentage@1 0.22 vs 0.17 best baseline (Table II).
- Ablation on GAIA: w/o heterogeneous message passing A@1 0.3845; w/o causal hyperedge 0.4679 (Table III).

## Artifact availability
Source code on a Google Drive link (footnote 1, §I); datasets are public GitHub repos (§IV-A1); no license, README or environment stated.

## Limitations / failure modes
No limitations section; only future work (§V). Baselines fail on dynamic topology; no repeated runs or CIs; compute and training settings (lr, epochs) not reported.

## Missing telemetry
Not treated. All three modalities are always present; per-neighbour attention weights could in principle down-weight a missing node (§III-B) but this is not tested.

## Fit note
