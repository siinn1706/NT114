## Question
How to choose a set of end-to-end probing paths (probing matrix) that maximizes link-failure detection/localization accuracy at low probing overhead in a data center network (Abstract, Sec.I, Sec.III-B).

## Method
Theoretical accuracy model for a given probing matrix (Sec.III-B, Eq. 6-9); greedy heuristic PMC using an enhanced path-selection indicator (Sec.IV); PPO deep-RL PMC algorithm (Sec.V). Failure localization itself reuses deTector's PLL algorithm (Sec.VI-A).

## Data and systems
Simulated 4-ary fat-tree (36 nodes), Python simulator plus ns-3, injected random link failure rates (Sec.VI-A). No real traces; not microservices.

## Modalities
Active network probes (packet-loss style probe results). Single modality, network layer.

## LLM
None.

## Baselines
Only deTector's PMC (Sec.VI-A; Table II).

## Metrics
Accuracy = detected failures / total failures, FNR, FPR (Sec.III-B, Eq. 7-9). No repeated runs or significance tests reported.

## Main results
Theory matches simulation (Sec.VI-B, Fig. 3). Table II: accuracy 63.68% / 83.19% (deTector), 72.13% / 85.87% (heuristic), 73.01% / 86.68% (DRL) for beta=2, 10 paths / beta=3, 15 paths. Figures garbled in extraction; Table II readable.

## Artifact availability
No code or data link in the text. CPU only (i7-8700, 32 GB, ~2 h PPO training, Sec.VI-D). PPO hyperparameters not listed.

## Limitations / failure modes
Matrix construction scalability to large DCNs; virtualized networks with irregular topology; topology generality of the DRL policy (Sec.VI-E).

## Missing telemetry
Not addressed as a telemetry-loss problem; probing path count is a design budget varied against accuracy (Sec.VI-C, Table II), which is probe selection rather than missing data.

## Fit to NT114
Out of scope: network-layer link failure detection, no service RCA, no AC@k/MRR, no NT114 datasets.
