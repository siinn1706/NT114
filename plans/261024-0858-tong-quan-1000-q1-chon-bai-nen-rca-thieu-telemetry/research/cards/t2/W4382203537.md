## Question
Combine traces, logs, metrics to localize the root-cause instance (Task 1) and classify failure type (Task 2), robustly under imbalanced failures (Abstract, S2.3).

## Method
Extract events (3-sigma on metrics/trace fields, Drain log templates), serialize per instance, learn fastText event embeddings with embedding-neighbour data augmentation (to 1000 per class), build dependency graph from traces + deployment (call edges both ways, co-deployment edges), TAGConv GNN with joint loss; rank instances in the predicted service group by event count (S4.2-S4.4).

## Data and systems
D1: GAIA simulation, 10 microservices + MySQL/Redis + 5 hosts, 5 failure types, 17 instances, 160 train / 939 test (Table 2; sums to 1099 failures of Table 1). D2: bank system, 18 instances, 80 train / 79 test, private (S5.1.1, Table 2). Time-based split.

## Modalities
Trace, log, metric plus deployment data (S2.1).

## LLM
None (fastText, GNN).

## Baselines
Task 1: MicroHECL, MicroRank, AutoMAP, MS-Rank, PDiagnose; Task 2: Cloud19, LogCluster, CloudRCA; own parameters per paper (S5.1.2).

## Metrics
A@k (eq. 5, denominator |A| test failures), Avg@5 (eq. 6), weighted precision/recall/F1; 5 repeats averaged, no significance test (S5.1.3, S5.1.4).

## Main results
- Avg@5 0.750 (D1), 0.790 in Table 4 vs 0.76 stated in text (D2); A@1 0.419 (D1), 0.646 (D2) (S5.2, Fig 8, Table 4).
- Failure type F1 0.839 / 0.800 (Table 3).
- Ablation: no augmentation D2 Avg@5 0.471 (Table 4).
- Missing metrics (62 D1 cases): DiagFusion A@1 0.274 / A@3 0.661 vs PDiagnose 0 / 0.161; full data 0.419 / 0.813 (S6.2, Table 6).
- Online 3-11 s per case on CPU (S5.4, Table 5).

## Artifact availability
Anonymous mirror anonymous.4open.science/r/DiagFusion-378D (S1, footnote 1); no license/run guide in text. D1 (GAIA) public on GitHub CloudWise; D2 private.

## Limitations / failure modes
Small datasets, simpler failures than industry; needs labeled historical failures and retraining for new service groups; accuracy drops when metric modality absent (S6.2, S6.3).

## Missing telemetry
Explicitly handled in S6.2 and S6.3: works with any two modalities; observational test on cases lacking metrics, one baseline, not an injected drop of each modality.
