## Question
Can labelled anomalies from a mature system train a pod-level RCL model for a new, unlabelled system (Sec. I, III-A)?

## Method (Sec. III)
- Aggregation-based event extraction: logs -> Drain templates -> 2 classes (connection/process) counts; metrics -> 3-sigma -> 6 event types (cpu/mem/net up/down); traces -> response time and call-count anomalies -> 4 event types.
- Per-modality domain-adversarial alignment (source vs target).
- "PageRank classifier": learnable instance weights + trainable alpha over reversed call graph (Eq. 2); ranks service instances.

## Data and systems
AIOps2021 (18 instances, 80 samples) and AIOps2022 (40 instances, 86 samples) (Sec. IV-A.1). Threats section also mentions TrainTicket but experiments do not use it.

## Modalities
Logs, metrics, traces (all three required in the design). No modality-drop experiment.

## LLM
None.

## Baselines
Pdiagnose, MS-Rank, Microscope (unsupervised); Eadro, DiagFusion (supervised, 2023). Only unsupervised ones in transfer setting (Sec. IV-B).

## Metrics
AC@1, AC@3, Avg@5; AC@k = hits in top-k / min(k,|r|) (Eq. 7-8). 95% CI over 10 runs, "within +/-1%" (Sec. IV-B).

## Main results (prose, Sec. IV-B)
- Supervised 60/40 split: average gain 30.17 / 43.2 / 24.18 / 47.27 / 18.9 points over baselines.
- Transfer: average gain 22.19 / 41.72 / 16.06 over unsupervised baselines.
- Ablation (Tables IV-V): PageRank classifier, event aggregation (w/o AE), domain adaptation (w/o DA) each help; cells not readable.
- Time (Table VI, AIOps2022): shorter than most baselines.

## Artifact availability
Code and preprocessed data: github.com/xsarvin/UDA-RCL (Sec. I footnote 2); license and run guide unknown from text. Hyperparameters in Sec. IV-A.4 (dim 5, lr 1e-5, 30 epochs, beta 1); window k and list length w not given. A100 stated.

## Limitations / failure modes (Sec. V)
Aggregation loses information; global-only alignment may cause negative transfer; noise sensitivity with few samples; 3-sigma normality assumption; assumes full trace coverage, real loss "clusters at failing services"; single-root faults only; small systems.

## Missing telemetry
Not handled by experiment; only the stated assumption of full trace coverage (Sec. V-B) and fixed 3-modality input. Cutting a modality is architecturally possible (per-modality branches) but untested.
