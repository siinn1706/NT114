# LogHyper-IB: Spatio-Temporal Hypergraph Representation Learning via Information Bottleneck for Anomaly Detection in Distributed Systems
- openalex_id: W7152617813; version read: publishedVersion (full text); text sha256: 43ad231dd9a5110f5983bce09854c4d70c5fc488db0980935e2eb3a3ed0eefac
- Question: detect anomalous log sessions on BlueGene/L and give interpretable root-cause attribution.
- Method: Drain3 templates -> hypergraph (templates=nodes, sliding windows=hyperedges) -> HGCN + Variational Information Bottleneck, supervised BCE+beta*KL (SIII, SIV.C).
- Data and systems: BGL only, ~4.75M messages, 70:10:20 chronological split (SIV.A). No microservice system.
- Modalities: logs only.
- LLM: none.
- Baselines: DeepLog, LogAnomaly, LogBERT, LogGPT, PLELog (SV.A, Table 2).
- Metrics: Precision/Recall/F1/MCC; latency; no top-k (SIV.C, Tables 1-3).
- Main results: F1 0.9899, MCC 0.9888 on BGL (Abstract, Table 2); RCA is one qualitative graph for Session 487 (SV.C, Fig. 8-9).
- Artifact: no code link or availability statement; BGL public; RTX 3090 24 GB used (SIV.B).
- Limitations: Drain3 errors propagate, single dataset, beta tuning, supervised labels (SVI.D).
- Missing telemetry: not handled; single modality, window-size sensitivity only (SVI.A).
