## Question
Can one fine-tuned LLM with an optimized chain-of-thought both find root-cause pods and issue autoscaling actions, without per-deployment retraining? (Abstract)

## Method
Prompt aggregator turns Prometheus/Jaeger telemetry and call graph into text with qualitative bins and special tokens (§IV.A-B, Table II). Four-step CoT (Analyzation, Fault, Counterfactual, Root cause in <root> tags). Training: SFT then GRPO/GSPO with reward = pod-level match + F-beta + format + length + KL (§V.C, Eq. 5-15). Autoscaling loop with counterfactual action (Algorithm 3).

## Data and systems
RCA: Murphy dataset on Hotel Reservation (§VI.A). Autoscaling: Sock-Shop and Train-Ticket on 5-node Kubernetes, Locust load with Alibaba trace. Own 80 GB annotated prompt-response corpus (Abstract, Intro contribution 1), release not stated.

## Modalities
Metrics (CPU/memory/latency), traces/call graph, fault signals, workload forecast (§IV.A). No logs.

## LLM
Base model not named in the text; fine-tuned with Unsloth/DeepSpeed ZeRO-3 on 4xA100 and 8xRTX 6000 Ada (§VI.A). Comparison LLMs: GPT-4o, DeepSeek-V3, Claude-3.5-Haiku via the same prompts (§VI.B).

## Baselines
RCA: ExplainIT, NetMedic, Sage, Murphy, plus three commercial LLMs. Autoscaling: KuScal, CoScal, FIRM (§VI.B).

## Metrics
RCA: recall, precision, accuracy with only the single most confident prediction counted (§VI.C.1); no formal definition of denominators. Autoscaling: RPS, response time, CDF.

## Main results
- ORACL RCA recall 0.83, precision 0.89, accuracy 0.92; Murphy has slightly higher recall (§VI.C.1).
- Table III: ORACL 0.89/0.83/0.92 vs GPT-4o 0.83/0.77/0.87, DeepSeek-V3 0.86/0.72/0.88, Haiku 0.61/0.45/0.77.
- Sock-Shop latency 162 ms vs 205-268 ms; Train-Ticket slightly worse than converged FIRM (§VI.D).
- No repeats or significance tests.
