# W4409916700 - Anomaly Detection and Root Cause Analysis in Cloud-Native Environments Using Large Language Models and Bayesian Networks

## Question
Detect anomalies in unstructured microservice logs with a fine-tuned LLM, then infer which service is the likely root cause with a dynamic Bayesian network, plus a chatbot (Abstract, §I).

## Method
MAIA: Llama-3 8B fine-tuned on normal logs predicts the next log message from 10 previous logs; sentence-similarity < 0.8 flags an anomaly (§V-A). Flagged services trigger trace analysis; a reliability score from duration, 2xx rate, P99, 5xx, recent deploy feeds pgmpy Bayesian network CPDs; variable elimination gives per-service outage probability (§V-B, "Baynet").

## Data and systems
Sock Shop (12 services) on AWS EKS with Istio, Loki, Tempo; Chaos Mesh faults (~10 min in a 30 min run) and Locust load; ~10% of log chunks labelled manually (§IV-V, Table 3, §V-A).

## Modalities
Logs (detection) then traces/Istio topology (RCA); metrics not used.

## LLM
Llama-3 8B (open), fine-tuned; role: next-log predictor for anomaly detection. A chatbot uses the same model (Abstract).

## Baselines
None.

## Metrics
Accuracy, precision, recall, F1 per chaos scenario for log anomaly detection (§VI-A, Fig. 16-17); no formal definitions or denominators; RCA metric none.

## Main results
- Precision mostly ~1.00; recall varies; Mongo IO failure recall 0.71, F1 0.83; queue disconnect recall 0.83 (§VI-A).
- RCA: frontend 90.0% outage probability (Fig. 18), shipping 78% with orders 12.16% (Fig. 19); two anecdotes, no top-k (§VI-B).

## Artifact availability
No code, model or dataset link in the text; only a Grafana snapshot URL (§VI-B).

## Limitations / failure modes
Low recall on some faults, possible overfitting at perfect scores, LLM neglects numerical values in logs, false positives (§VI-A, §VII).

## Missing telemetry
Not treated. The BN skips services with no intercepted traces (probability near 0), which conflates unaffected with unobserved (§VI-B).

## Fit note
Sock Shop and an open 8B model are relevant, but there is no RCA evaluation, so it cannot serve as base paper.
