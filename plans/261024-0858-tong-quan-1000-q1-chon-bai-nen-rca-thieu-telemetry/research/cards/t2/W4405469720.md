# W4405469720 - Rethinking software misconfigurations in the real world: an empirical study and literature analysis

- Question: what are the root causes of real-world misconfigurations, how has troubleshooting literature evolved, how practical are the tools/datasets, what challenges remain (RQ1-RQ4, Sec 1).
- Method: manual open coding of 772 issues selected from 168,054 user issues (two online communities, three customer service channels) into four root-cause classes (constraint violation, resource unavailability, component integration error, configuration semantic misinterpretation); systematic mapping of 60 papers 2003-2024 (Sec 3, 4, 5).
- Data and systems: issue text and paper metadata; no running system, no telemetry.
- Modalities: not applicable (issue text).
- LLM: none used.
- Baselines: none. Metrics: Cohen kappa 0.72 for paper screening (Sec 3.3), kappa for labeling (Sec 3.4).
- Main results: taxonomy (Fig 3, Sec 4); shift of targets to cloud/advanced applications and non-crash cases (Sec 5.1); only 11 tools and 4 datasets publicly available (Abstract, Sec 6, tool/dataset tables).
- Artifacts: dataset and replication package public at github.com/anabioticsoul/misconfiguration datasets (Sec 1, Sec 3.3 footnote 15); license not stated in text.
- Limitations: Threats to Validity (Sec 8): sampling of forums/trackers, paper search completeness, English-only. Generic.
- Missing telemetry: not addressed.
- Note: useful only for citing misconfiguration as a fault class and the reproducibility gap in the field; not an RCA method.
