# W4410538768 - RCRank: Multimodal Ranking of Root Causes of Slow Queries in Cloud Database Systems

- Version read: preprint (PVLDB 18(4) submittedVersion), 14 pp; text sha256 4cd0c2f3158202d10c68419796d3a1912c5fd1b31886492dc6d5f3286814fd8e
- Reader r1; F total 21 (F1 3, F2 5, F3 7, F4 3, F5 1, F6 2); t2_gate 1
- Question: for a slow query in a cloud database, identify valid root-cause types and rank them by impact (speedup if fixed). Cloud DB domain, not microservices; output is cause types, not components (Sec 3.3).
- Method: four modality encoders (SQL via BERT, plan via QueryFormer, log via MLP, KPIs via 2D-CNN), self-supervised cross-modal masked pre-training, root-cause-adaptive cross Transformer with gating, impact-aware loss (order + validity) (Sec 4.3, Algorithm 1).
- Data and systems: Hologres1/2 (Alibaba production, proprietary), TPC-C, TPC-H, TPC-DS (LLM-generated queries on Postgres, labels from rule-based or LLM-based revision and re-execution) (Sec 5.1.1, Table 2, Sec 4.2).
- Modalities: SQL text, execution plan, execution log, KPIs.
- LLM: not in the model; used to generate synthetic queries and revisions for labels (Sec 4.2, 5.1.1); baseline D-Bot with GPT-3.5 or vicuna-13B (Sec 5.2.1).
- Baselines: OpenGauss (adapted), D-Bot, Concat, Only-SQL/Plan/Log/KPI (Sec 5.1.2).
- Metrics: V-ACC, Top1-ACC, MSE+-std, MC-ACC, Kendall Tau, Top1-IR (Sec 5.1.3), defined with ratios; 8:1:1 split, no seeds/significance (timing averaged over 5 runs, Sec 5.2.3).
- Main results: Hologres1 Top1-ACC 0.5384 vs Concat 0.5071, OpenGauss 0.5032, D-Bot(Vicuna) V-ACC 0.3769 (Table 3); TPC-C Top1-ACC 0.6417 vs 0.5619 (Table 4); TPC-DS Top1-ACC 0.6321 vs 0.5566 (Table 5); ablations (Table 6); single-modality results show Only-Log weakest (Tables 3-5); main-modality study Table 9; end-to-end speedup 24-31% (Table 8); inference 0.018 s/query (Table 7).
- Artifacts: code/data/artifacts at github.com/decisionintelligence/RCRank (PVLDB Artifact Availability); license and run steps not in text; Hologres data proprietary. Trains on one RTX 3090 (Sec 5.1.4).
- Limitations: no limitations section; future work on incremental training for new root causes and revision plans (Sec 6). Fixed root-cause taxonomy of 5 or 10 types.
- Missing telemetry: modality subset training (Only-X, Concat, main modality) reports per-condition results, but modalities are removed at training time, not noised or dropped at inference; no robustness to partial data.
- Note: transferable idea is modality-gated fusion with per-modality ablation reporting; domain differs from microservice RCA.
