## Question
Does native replay performance of incident-response agents (detect, localize, cite evidence, choose safe action) transfer to external diagnostic traces? (Abstract)

## Method
Deterministic synthetic generator over 5 domains (microservice, HVAC, water grid, manufacturing, bioprocess), topology-coupled delayed propagation (Eq. 1-3, §III.D); native composite score (Eq. 4-13, §III.E); External Portability Score EPS (Eq. 14, §III.F). Topologies only 4-6 nodes (§III.D).

## Data and systems
Native: 5 seeds x 500 episodes = 2,500 (§IV.B). External: 270 RCAEval RE2 episodes (Online Boutique, Sock Shop, Train Ticket) + 510 LBNL FDD HVAC episodes = 780 (§V.C). Hidden-seed audit 2,800 predictions (§V.D).

## Modalities
Sensor/metric streams, logs, operator notes, manuals, topology; RE2 adds metrics, logs, traces (§IV.B).

## LLM
Seven local Ollama open-weight models (gemma4:e2b/e4b/26b, qwen3.5:4b/9b, granite4.1:3b/8b), ReAct-JSON runner, temp 0, 8192 ctx, Quadro RTX 8000 49 GB (§IV.C, §V.H). Role: agent policy producing prediction JSON.

## Baselines
no-op, random, threshold, topology-RCA (MicroRCA/CloudRanger-style heuristic), oracle (§IV.A). Learned RCA (Eadro, CausalRCA, CHASE) explicitly NOT run (§V.K "Deferred learned-RCA comparison").

## Metrics
S_rc = 0.5 top1 + 0.3 top3 + 0.2 graph-distance term (Eq. 5); span F1 (Eq. 9); strict RCA@1/@k on component+fault (§V.C); bootstrap CIs, paired bootstrap, Cohen dz (§V.A).

## Main results
- gemma4:26b native composite 0.939; 0.493 without evidence (Abstract; §V.E Table 10).
- Hidden-seed topology audit 0.941 on both variants (§V.D Table 9).
- External EPS: threshold and topology heuristics 0.789, gemma4:26b 0.364, gemma4:e4b 0.240 (§V.C Table 8).
- Failure mode: component-only or free-text labels get zero strict RCA credit (§V.C checkout-service CPU-fault example).

## Artifacts
Public GitHub repo pz1004/causalopsbench-public, MIT license, commands/manifests in repo docs; model tags not redistributed; RCAEval raw data not redistributed (§IV.D, §V.K).

## Limitations
Synthetic simulator; tiny topologies; one hidden seed with 200 episodes per variant; LBNL evidence labels are proxies; no noisy/missing/delayed telemetry testing ("do not constitute ... certification under noisy, missing, delayed, or contradictory production telemetry", §V.I); no learned-RCA rows (§V.K).

## Missing telemetry
Not tested as telemetry degradation; only a view ablation drops the evidence/topology/manual views (§V.E Table 10: evidence removal is the largest drop) and explicitly lists missing/noisy telemetry as unmeasured (§V.I, §V.K).
