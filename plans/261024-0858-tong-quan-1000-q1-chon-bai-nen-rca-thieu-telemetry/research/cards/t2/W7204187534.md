# W7204187534 - Topo-MFP: Topology-aware multimodal propagation learning for fault detection and root cause localization in microservice systems

## Question
Rank root-cause services (symptom-to-source) and detect faulty services by jointly modelling metrics, logs and traces with service topology (Abstract, §3).

## Method
Stage 1: SBERT + log-template transition graph, spatio-temporal graph attention, cross-modal fusion for detection (§4.1-4.3). Stage 2: per-modality dilated-conv propagation graphs, contrastive consistency fusion, topology-aware soft sparsity prior, reverse random walk with restart for ranking (§4.4-4.5).

## Data and systems
AIOps2022 (CCF challenge, industrial e-commerce) and TT, a TrainTicket-based set built by the authors (41 services, Chaosblade; §5.2, Table 4). Operation labels mapped to service labels (§5.3, Tables 5-7).

## Modalities
Metrics, logs, traces; all three required in the main model (§3).

## LLM
None; Sentence-BERT embeds log templates (§4.1).

## Baselines
RCA: MRCA, MicroHECL, DiagFusion, plus Local-Score, Topology-RWR, Random (§5.5, Table 11). Detection: UAC-AD, TraceVAE, USAD. CHASE, RUN, Grace, MicroEGRCL excluded on purpose.

## Metrics
Hit@K, MAP@K per case (§5.6); precision/recall/F1/AUC for detection; mean +/- sd over five seeds (§6.1).

## Main results
- AIOps2022 Hit@1 0.872+-0.010 vs DiagFusion 0.667, Topology-RWR 0.724 (Table 18).
- TT Hit@1 0.901+-0.009 vs MicroHECL 0.784, Topology-RWR 0.824 (Table 19).
- Hit@5 is near saturation: Random reference 0.779 on AIOps2022 (Table 18).
- Ablation w/o log semantics Hit@1 0.813 (AIOps2022), 0.841 (TT) (§6.6, Tables 22-23).
- Wilcoxon p=0.063 vs Topology-RWR, the floor for n=5 (Table 13).

## Artifact availability
Reproducibility package described in future tense (scripts, configs, seeds); no URL or license; TT dataset release unstated (§10).

## Limitations / failure modes
Candidates limited to services seen in the window; service-level labels easier than operation-level; no edge-level ground truth; only two small systems (6-7 services on average, Table 3) (§5.3, §8.3, §9).

## Missing telemetry
No missing-data experiment. Only detection-stage modality ablation (Table 16, drops logs/traces/metrics) and RCA ablation of log semantics; inference needs all three modalities.
