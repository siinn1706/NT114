# W4396929864 - MTG_CD: Multi-scale learnable transformation graph for fault classification and diagnosis in microservices

- Version read: published journal (J Cloud Comput 2024, "as reused" from phase 02 map), 15 pp; text sha256 c4772edb6df03cdbd93e3540897e2e61508ac3c52f5847addb12dc4d78bb93e1
- Reader r1; F total 12 (F1 4, F2 0, F3 4, F4 1, F5 1, F6 2); t2_gate 0
- Question: classify fault type (normal, CPU, memory leak, network latency) from multivariate monitoring metrics per service, then give a coarse diagnosis of fundamental services.
- Method: multi-scale neural transformations plus learnable graph adjacency, GCN fusion, multi-scale convolution classifier (Method sections, Fig 2). Diagnosis step: PC algorithm causal graph then PageRank random walk, top-2 services (Sec "System fault diagnosis results", Fig 6).
- Data and systems: Sock Shop, 7 core services, faults injected (CPU, memory leak, network delay), each repeated >=5 times, 5 s sampling; per-service datasets (Table 1: 35-36 dims, ~3.2k train / ~1.4k test, 4 classes).
- Modalities: single (service latency + container resource metrics time series).
- LLM: none.
- Baselines: HMM, NaiveBayes, RandomForest, OmniAnomaly, CNN, TranAD, GDN (Baselines, Table 3).
- Metrics: macro-F1, macro-Precision, macro-Recall, macro-Acc, named but not defined; no AC@k.
- Main results: highest macro-F1 on all eight datasets, average macro-F1 gain 14.05% (Abstract, Table 3, Fig 5); ablation (Table 4, e.g. Payment 0.9426 vs 0.9115 w/o MNT); k sweep (Table 2); diagnosis only qualitative (Table 5 PageRank top-2 per fault type, no ground-truth score).
- Artifacts: no code link; "No datasets were generated or analysed" (Availability statement). 2080Ti 12 GB, PyTorch 1.4 (Experimental settings).
- Limitations: future work generic (Conclusions): go beyond service level, improve classification. Localization not evaluated; only 3 fault types, supervised labels needed.
- Missing telemetry: not addressed; metrics only, no modality ablation or missing data test.
- Note: shows classical RF/NaiveBayes beating deep anomaly detectors on this classification task; evidence for simple baselines.
