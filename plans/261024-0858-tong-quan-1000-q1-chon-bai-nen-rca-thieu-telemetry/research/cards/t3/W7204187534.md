## Problem
Service-level fault detection plus root-cause service ranking from metrics, logs and traces, separating roots from downstream-affected services (Abstract, Sec.1, Sec.3).

## Assumptions
Candidate set = services seen in the diagnosis window (Sec.4.4.1, Sec.5.3); operation-level labels are merged to service level (Sec.5.3, T5-T6); all three modalities present; supervised training on labelled windows; symptoms at downstream services or KPIs (Sec.3.2, Sec.4.5).

## Method (data flow / control flow)
Stage 1 detection: Drain templates -> SBERT -> transition-graph gated attention; GRU metrics; trace-derived dynamic service graph; spatial/temporal attention; cross-modal fusion (Sec.4.1-4.3). Stage 2 RCA: per-modality shared-kernel dilated convolution -> modality propagation matrices -> contrastive consistency fusion + topology-aware soft sparsity (rho_in 0.10, rho_out 1.00) -> reverse random walk with restart (alpha 0.15) from abnormal-score restart vector (Sec.4.4-4.5, T12, Algorithm 2). No LLM.

## Modalities
Metrics, logs, traces; all required in the main model (Sec.3, Sec.4).

## LLM role
None. Sentence-BERT embeds log templates (Sec.4.1.1); checkpoint not named.

## Datasets / splits
AIOps2022 (156 RCA cases, 101/23/32) and author-built TT, Train-Ticket 41 services, 108 injections, 70/16/22, Chaosblade (Sec.5.2, Sec.5.4, T3-T4, T9). Split by fault interval/injection case; 7-h normal baseline for TT (Sec.5.2).

## Baselines
RCA: MRCA, MicroHECL, DiagFusion (adapted to one protocol) plus Random reference, Local-Score, Topology-RWR (Sec.5.5, T11). CHASE, RUN, Grace, MicroEGRCL, DGERCL excluded on purpose (Sec.5.5, Sec.9).

## Metrics (+denominator)
Hit@K over N RCA cases; MAP@K with min(K,|G|); detection P/R/F1/AUC; five seeds 2022-2026; Wilcoxon over seeds (Sec.5.6, Sec.6.1). Denominator is the candidate set of the diagnosis window (mean 6.1 AIOps2022, 7.0 TT), not all services (Sec.5.3, T7).

## Main results
- AIOps2022 Hit@1 0.872+-0.010, MAP@3 0.891 vs DiagFusion 0.667, Topology-RWR 0.724 (T18).
- TT Hit@1 0.901+-0.009 vs MicroHECL 0.784, Topology-RWR 0.824 (T19).
- Detection F1 0.949 / 0.951 vs TraceVAE 0.934 / 0.940 (T14-T15).
- Ablation w/o log semantics Hit@1 0.813 / 0.841 (T22-T23); SBERT beats TF-IDF/BERT (T20-T21).

## Cost
RTX 4090 24 GB, Python 3.9, PyTorch 1.13, CUDA 11.7 (T2, Sec.5.1). No training time, VRAM or inference latency; only O(w n^2 d) complexity, no pruning (Sec.8.4).

## Limitations
Service-level labels easier than operation-level (Sec.5.3, Sec.9 fourth); no edge-level propagation ground truth (Sec.8.1, Sec.8.5); no large-scale graphs (Sec.8.3, Sec.11); secondary ablations single-run (Sec.9 third).

## Threats
Two datasets (Sec.9 first); excluded recent baselines (Sec.5.5, Sec.9 second); adaptation bias in baselines (Sec.9 fourth); no production readiness (Sec.9 sixth).

## Counter-evidence
- Hit@1 means are arithmetically impossible as case-level means: 5 seeds x 32 (or 22) test cases cannot give 0.872, 0.724, 0.667, 0.901, 0.824 (9 of 10 checked means) - the metric unit or denominator is unclear (T9, T18-T19, Sec.5.6; scratchpad chk.py).
- p=0.063 for every RCA comparison with Topology-RWR (T13, Sec.6.1); only 22-32 fixed test cases (T9).
- Hit@3/5 near random-plus-saturation: Random Hit@5 0.779 (T8, T18).
- Data availability says no datasets generated although TT was built (Data availability; Sec.5.2).
- No RCA experiment with a modality missing at inference; only detection ablation without seeds (T16, Sec.6.3, Sec.9).

## h1-compat
yes: ranking of candidate services (3-13) with stationary RWR probabilities (Sec.4.5, T7); scores uncalibrated.

## Missing-telemetry handling
Not addressed for RCA. Detection ablation retrains without logs/traces/metrics (F1 0.889/0.914/0.916 vs 0.949, T16); RCA ablation removes only log semantics, regularisation or consistency fusion (T22-T23). Inference requires all three modalities (Sec.3.1).

## Core kept under single-LLM
Non-LLM learned propagation graph + topology prior + reverse RWR, run upstream and handed to the one LLM as a ranked evidence list (Sec.4.4-4.5). It needs supervised training per system and all three modalities, and the training-free Topology-RWR sub-core already gives 0.724 / 0.824 Hit@1 (T18-T19). Whether a trained upstream model fits the single-LLM invariant is for the project owner.
