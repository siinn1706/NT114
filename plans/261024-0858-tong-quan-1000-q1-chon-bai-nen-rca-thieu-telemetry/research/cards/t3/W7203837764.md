## Problem
Locate the root-cause service instance of one anomalous trace using traces, logs and metrics jointly in one end-to-end trained model [Abstract; §I, p.1-2].

## Assumptions
- A labelled root-cause instance per anomalous trace exists for supervised training (160 GAIA traces) [§IV-A1, p.7; Eq.15, p.7].
- Trace invocation topology is always available and defines the hypergraph (ancestors/descendants) [§III-C, Alg.1, p.6].
- All three modalities exist for every instance; one log node and several metric nodes per instance [§III-A, p.4].

## Method (data flow / control flow)
1. Per trace build a graph: instance nodes + 1 log node + n metric nodes per instance (§III-A, p.4-5).
2. Encode logs (FastText on templates), metrics (HF time-series transformer, last step), instances (one-hot + positional) (Eq.1-2, p.5).
3. Heterogeneous attention: softmax over an instance's log/metric neighbours gives anomaly weights; update with gamma=0.5 mix (Eq.3-9, p.5-6).
4. Drop log/metric nodes; build hyperedges from parent/ancestor sets and descendant sets (Alg.1, p.6); one hypergraph convolution layer (Eq.14, p.7).
5. Detection head + softmax over instances, cross-entropy against the labelled root (Eq.15, p.7). Single forward pass per trace; no iteration or LLM.

## Modalities
Traces (topology), logs (templates), metrics (time series) [§III-A, p.4-5].

## LLM role
None. Only future work: an LLM encoder could replace the log/metric encoders [§V, p.10].

## Datasets / splits
- GAIA/MicroSS: 10 instances, 1,099 static traces, 160 train, rest validation+test (ratio not given) [§IV-A1a, p.7].
- AIOps 2020: 68 injected failures over 3 months, dynamic topology, only a detection percentage reported [§IV-A1b, p.7-8].

## Baselines
PC, GES, CloudRanger, MicroRCA, TrinityRCL, CausalRCA, DiagFusion; PC/CloudRanger/CausalRCA are n/a on AIOps 2020 [§IV-A2, p.7-8; Table II note, p.8].

## Metrics (+ denominator)
A@1, A@3, Avg@5 over |D| anomaly traces (Eq.16-17, p.8); |D| is not reported. Percentage@n = flagged traces / all traces in n minutes after the labelled start (Eq.18, p.8): a detection rate, not a root-cause rank.

## Main results
- GAIA A@1 0.6135, A@3 0.8823, Avg@5 0.8276 vs best baseline TrinityRCL 0.4503/0.8244/0.7651 [Table II, p.8].
- AIOps 2020 Percentage@5/3/1 0.15/0.16/0.22 vs best 0.12/0.14/0.17 [Table II, p.8].
- Ablation (GAIA): w/o heterogeneous message passing A@1 0.3845; w/o causal hyperedge 0.4679; w/o instance embedding 0.5927 [Table III, p.10].

## Cost
Not reported: no training time, epochs, learning rate, GPU or memory anywhere [§IV-A2, p.8]. Static estimate from architecture: 3 attention layers x 8 heads, d=128, one hypergraph layer, graphs of ~10 nodes (GAIA) [§IV-A1-2, p.7-8].

## Limitations
- No limitations section; only future work (spatiotemporal hypergraph, LLM encoder) [§V, p.10].
- Baselines marked inapplicable on dynamic topology, so AIOps 2020 comparison is partial [§IV-B, p.9].

## Threats
- Single result per cell, no repeats, no CI or significance test [Table II-III, p.8-10].
- GAIA is one system, 10 instances: top-3/top-5 chance level is high (3/10, 5/10) [§IV-A1a, p.7].
- Supervised on 160 traces of one injected-fault family; transfer to NT114 datasets is untested [§IV-A1a, p.7].

## Counter-evidence
- The only real RCA evaluation is GAIA; AIOps 2020 reports a detection percentage whose 5-min window dilutes anomalies [§IV-A1b, p.8; Eq.18, p.8].
- A@3 gain over TrinityRCL is small (0.8823 vs 0.8244) and Avg@5 gain 0.8276 vs 0.7651 [Table II, p.8].
- Several baseline rows fit no single integer |D| (<=1100), suggesting averaging or differing test sets that are not disclosed [Table II, p.8; check in work/t3/W7203837764-evidence.csv].
- Removing the causal hyperedge costs 23.7% relative A@1 but A@3 stays 0.8106 [Table III, p.10].

## h1-compat
yes: softmax score per instance gives a full ranking with confidence (Eq.15, p.7); ranking is over <=10 instances per trace on GAIA, so top-5 is trivially wide.

## Missing-telemetry handling
None evaluated. Softmax over neighbours (Eq.5) would renormalise if a log/metric node vanished, untested; traces are structural (hyperedges) so a no_trace condition removes the core [§III-B-C, p.5-6].

## Core kept under single-LLM
Heterogeneous modality attention + causal-hypergraph propagation as a trained non-LLM scorer; a local LLM could only be bolted on as post-hoc explainer or re-ranker. The trained scorer needs labelled traces and trace topology.
