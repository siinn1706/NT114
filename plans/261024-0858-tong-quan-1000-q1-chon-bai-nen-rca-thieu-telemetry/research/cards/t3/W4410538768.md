## Problem
Given a slow query in a cloud DB, estimate the impact (relative runtime saving, Eq 1) of each internal root-cause type and rank the valid ones (impact > 10%) (Sec 3.2-3.3, Sec 5.1.1). Cloud DB, not microservices; the output is cause types, not components.

## Assumptions
- Fixed taxonomy of 5 types (Hologres, TPC-DS) or 10 types (TPC-C/H); external causes (I/O, network) are out of scope (Sec 1, Sec 5.1.1).
- All four modalities are available at diagnosis time and labels come from re-executing revised queries (Sec 3.1, Sec 4.2).

## Method (data and control flow)
- Offline: collect slow queries (>1 s), revise by rule (statistics, join order) or LLM (index, distribution key, query rewrite), re-execute, record impact (Sec 4.2).
- Model: BERT (SQL), QueryFormer (plan), MLP (log), 2D-CNN (KPI); masked-prediction pre-training; common + root-cause-gated cross-modal Transformers with SQL as query modality; MSE + validity + order losses (Sec 4.3, Eq 4-17, Algorithm 1).
- Inference: one forward pass gives impact per cause, threshold 10%, sort (Sec 4.3.4).

## Modalities
SQL text, execution plan DAG, execution log vector, KPI time series (Sec 3.1).

## LLM role
None in the model. LLM generates synthetic TPC queries and index/distribution/rewrite revisions to label data (Sec 4.2, Sec 5.1.1). Baseline D-Bot uses GPT-3.5 or vicuna-13B with multiple dialogue calls (Sec 5.2.1, Sec 5.2.3).

## Datasets/splits
Hologres1 (2209 slow), Hologres2 (2701), TPC-DS (7246), TPC-C (5764), TPC-H (4279) slow queries (Tab 2); split 8:1:1; pre-training uses all other queries (Sec 5.1.4). Hologres is proprietary (README).

## Baselines
OpenGauss re-implemented as plan+KPI fusion with an FC head; D-Bot (LLM); Only-SQL/Plan/Log/KPI; Concat (Sec 5.1.2).

## Metrics (+denominator)
V-ACC (ratio of correctly estimated valid causes over all causes), Top1-ACC, MSE+-std, MC-ACC (consistently ordered lists / m queries), Kendall Tau, Top1-IR (mean impact of predicted top-1) (Sec 5.1.3). Denominator = test slow queries; test n is not given.

## Main results
- Hologres1 Top1-ACC 0.5384 vs Concat 0.5071, OpenGauss 0.5032, D-Bot(Vicuna) V-ACC 0.3769 (Tab 3).
- TPC-C Top1-ACC 0.6417 vs 0.5619; TPC-DS 0.6321 vs 0.5566 (Tab 4, Tab 5).
- Revised top-1 cause cuts runtime 24.18-30.54% end to end (Tab 8); training 1.76 min/epoch, inference 0.018 s/query vs D-Bot 5.17 s (Tab 7).

## Cost
RTX 3090, batch 64, 50 epochs (Sec 5.1.4); inference 0.018 s/query (Tab 7). No API tokens at inference; LLM spend only for labels (not reported).

## Limitations
- No limitations section; future work only: revision plans over query sets, incremental training for new causes (Sec 6).
- Fixed cause taxonomy cannot add a cause without retraining (Sec 6, Sec 5.1.1).

## Threats
- Single run per cell; no seeds, CI or significance test (Sec 5.1.4; 5 runs only for timing, Sec 5.2.3).
- TPC labels depend on LLM-generated queries and LLM-recommended fixes, so labels are only as good as the generated revisions (Sec 4.2, Sec 5.1.1).
- Hologres, the only real dataset, is not released (README; Sec 5.1.1).

## Counter-evidence
- Only-Plan beats Concat on MC-ACC for Hologres1 (0.2281 vs 0.2132) (Tab 3).
- w/o pre-train has lower MSE (0.1119 vs 0.1164) on Hologres than the full model (Tab 6).
- Tab 9 SQL-main row is identical to the Tab 6 w/o pre-train row, and the Tab 6 pre-train Hologres Top1 0.4985 matches neither Hologres1 (0.5384) nor Hologres2 (0.4335) in Tab 3 (Tab 3, 6, 9).
- Gains over Concat on Hologres are small (Top1-ACC +6.17%, +2.24%) (Tab 3).
- Modalities are removed at training time only; no inference-time missingness (Sec 5.1.2, Tab 3-5).
