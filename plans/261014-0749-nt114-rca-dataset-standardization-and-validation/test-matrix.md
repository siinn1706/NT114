# TDD test matrix

Run from `RCA_ROOT` inside the project venv:

- Fast suite (synthetic fixtures, no raw data): `PYTHONPATH=src python -m pytest -q tests -m "not realdata"`
- Real-data samples (needs `data/raw` VERIFIED): `PYTHONPATH=src python -m pytest -q tests -m realdata`
- Acquisition tests (unchanged): `python -I tests/test_datasets_acquire.py`

Fixtures are generated by code (`tests/fixtures/build_fixtures.py`) into a pytest `tmp_path`: tiny
zips and directories that mimic each raw layout, including the known defects (duplicate
`multi-source-data`, `_f3_1`, header-only traces, `root_cause.txt`, Nezha +2e8 offset, `._*`
members, unsafe tar members). No binary fixtures are committed. `pytest.ini` registers the
`realdata` marker.

Write each test before the code it covers (red → green) inside its phase.
